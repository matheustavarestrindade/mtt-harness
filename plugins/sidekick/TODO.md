# Sidekick Checks

- [x] The plugin uses harness interfaces.
- [x] Event handlers do not run models or read files.
- [x] Memory retrieval uses the `medium` compression level.
- [x] File retrieval stays in the workspace and has read limits.
- [x] The worker can give an empty result.
- [x] A Sidekick note must have source references.
- [x] A previous task cannot supply a Sidekick note.
- [x] The database keeps Sidekick notes when the harness stops.
- [x] Session removal rejects a previous worker result.
- [x] Revert stops related workers before the history change.
- [x] The startup prompt does not change because of a Sidekick note.
- [x] The UI uses harness plugin routes.
- [x] Live model checks examine memory retrieval and file retrieval.
